# 🎓 ApplyMate

A Flask-based student onboarding platform with role-based dashboards for **students**, **admins**, and **assigners**.

## 🚀 Quick Setup

    git clone https://github.com/suryachandrasoma/applymate.git
    cd applymate
    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    python init_db.py
    python app.py

Open http://127.0.0.1:5000

## 🔑 Default Logins

- **Admin** — admin@applymate.com / Admin@123
- **Assigner** — assigner@applymate.com / Assigner@123
- **Student** — Sign up via /signup
